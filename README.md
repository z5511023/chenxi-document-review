# 辰溪抽水蓄能电站工程文件审核助手

基于大语言模型的智能工程文件审核系统，面向水利水电工程领域，为总包、监理、施工三类单位提供差异化审核服务。

## 功能特性

### 智能文件审核
- **多格式文件解析**：支持 PDF、Word(.docx)、图片、纯文本，前端浏览器内解析，仅传输文本，无文件上传限制
- **SSE 流式响应**：实时推送审核进度（启动→检索→分段审核→完成），避免长时任务超时
- **分类标注检测**：自动识别格式错误、错别字、过期规范、参数不合规、内容缺失等 6 类问题
- **报审单专项审核**：签字栏完整性、日期逻辑、签章/电子印章、监理签认、格式规范 5 大维度检查
- **智能分段审核**：大文件按章节切分（快速 40k/详细 60k），逐段审核后合并，保证全文覆盖

### 单位差异化审核
- **总包单位**：EPC 总承包六维审核（设计施工一体化/施工组织/分包管理/质量安全体系/环保/应急）
- **监理单位**：七大维度审核（合规性/技术/质量/安全/危大工程/管理/应急度汛）
- **施工单位**：六维审核（设计符合性/工艺/质量/安全/进度/环保）

### 知识库 + 联网搜索
- **公共知识库**（6 个数据集）：人员资质、企业资质、技术文件、安全检查、公文审核、通用法规
- **单位私有知识库**（15 个数据集）：按单位类型×模块划分，支持独立上传管理
- **检索优先级**：文字约束(PROMPT) → 公共知识库 → 单位私有知识库 → 联网搜索（冲突以知识库为准）
- **联网搜索兜底**：知识库匹配不足时自动触发，补充最新法规标准

### 管理后台
- **知识库管理**：顶级 Tab 切换公共/总包/监理/施工，各单位独立上传和审核依据配置
- **审核依据配置**：智能检索模式 / 文字约束模式（PROMPT），支持一键填充默认审核标准
- **用户管理**：账号创建、角色分配、单位归属管理
- **审核历史**：管理员查看全部记录，普通用户仅查看自己的

## 技术架构

```
┌─────────────────────────────────────────────┐
│                  浏览器端                     │
│  pdf.js / JSZip / File.text → 纯文本提取     │
│  fetch + ReadableStream → SSE 流式渲染        │
└──────────────────┬──────────────────────────┘
                   │ JSON POST（纯文本）
┌──────────────────▼──────────────────────────┐
│            Express 后端 (5000)                │
│  ① 文字约束(PROMPT) → 优先级最高              │
│  ② 公共知识库检索 → Coze Knowledge            │
│  ③ 单位私有知识库检索 → Coze Knowledge         │
│  ④ 联网搜索（知识库不足时）→ Coze Web Search   │
│  ⑤ 组装模块专用提示词 → LLM 分段审核           │
│  ⑥ SSE 推送进度 → 存入 Supabase              │
└─────────────────────────────────────────────┘
```

| 服务 | 用途 |
|------|------|
| Supabase | 用户账号 + 审核记录持久化 |
| Coze Knowledge | 公共 + 单位私有知识库检索 |
| Coze Web Search | 知识库不足时联网搜索补全 |
| doubao-seed-2-0-pro | 旗舰级智能文件审核引擎 |

## 快速开始

### 环境要求

- Node.js 24+
- pnpm

### 安装与运行

```bash
# 安装依赖
pnpm install

# 启动开发服务器（端口 5000）
pnpm dev

# 构建生产版本
pnpm build
```

### 环境变量

通过平台自动注入，无需手动配置：

| 变量名 | 说明 |
|--------|------|
| `COZE_SUPABASE_URL` | Supabase 项目地址 |
| `COZE_SUPABASE_ANON_KEY` | Supabase 匿名密钥 |
| `COZE_SUPABASE_SERVICE_ROLE_KEY` | Supabase 服务端密钥 |
| `DEPLOY_RUN_PORT` | 服务端口（默认 5000） |

### 默认账号
